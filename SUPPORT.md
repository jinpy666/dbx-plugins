# Support

For usage questions, open a GitHub Discussion or an issue and include:

- DBX version and operating system;
- plugin ID and version;
- whether the issue is desktop or web/Docker;
- a redacted error message and reproducible steps;
- relevant smoke or sidecar output with secrets removed.

Do not include connection exports, passwords, tokens, private keys, or customer
data. Security reports belong in [SECURITY.md](SECURITY.md), not in a public issue.
